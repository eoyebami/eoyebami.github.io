### Overview

![alt text](images/lex/image.png)
* AWS `Lex` is a fully manage AWS service for building conversational voice and text interfaces into any application
    - it combines `automatic speech recognition (asr)` and `natural language understanding (nlu)` to handle complex, multi-turn interactions
        * `asr`: allows `lex` to interpret user input that its hearing and convert that text to speech
        * `nlu`: used to understand the intention of the text
    - it is a user-to-chatbot interaction 
    - it uses `nlu` to derive intent  from text or voice input to provide highly engaging user experiences with lifelike conversational interactions
    - although `comprehend` can be used to uncover insights and connections in text, it cannot be used to create a chatbot like experience
    - it can be used with `lambda` to accept `lex events` and return a structured response for lex
        - you can go into intent settings in `lex` to enable `lambda` for dialog validation or fulfillment
